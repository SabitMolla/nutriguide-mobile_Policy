# nutriguide-mobile_Policy
this is the privacy policy website for nutriguide

## Publish to GitHub Pages

1. Commit and push the repository to `main`.
2. In GitHub, open the repository settings and go to `Pages`.
3. Set the source to the `main` branch and the root folder.
4. Wait for GitHub to finish building, then open the Pages URL.

The site root now loads `PrivacyPolicy.html` through `index.html`, so GitHub Pages will open the policy page directly.
